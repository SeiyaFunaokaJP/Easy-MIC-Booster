## メインウィンドウ {#main-window}

| エリア | 内容 |
|:-----|:-------------|
| **ヘッダー** | ステータス表示（動作中 / バイパス中 / デバイスの問題。サンプルレートと遅延も表示）、**BOOST ON** スイッチ、設定の歯車 |
| **ルーティング** | レベルメーター付きの入力・出力デバイスと、デバイスプロファイル |
| **プリセット** | 自分のプリセットと組み込みプリセット |
| **サウンド** | ゲイン、シンプル / イコライザーのモード切り替え、リアルタイムスペクトル付きの EQ グラフ |
| **ノイズ抑制** | オン/オフ、方式、強さ |
| **ノイズゲート** | オン/オフとしきい値 |

**BOOST ON** はゲインと EQ のオン/オフを切り替えます。オフの間はマイクの音声が元のレベルのまま通過します。ノイズ抑制とノイズゲートは設定どおり動作し続けます。

## 信号の流れ {#signal-chain}

音声は次の順にエフェクトを通過します。

```
入力 → ノイズ抑制 → イコライザー → ゲイン → ノイズゲート → リミッター → 出力
```

処理は内部的に 48 kHz モノラル（ノイズ抑制が想定する形式）で行われます。そのため、
どのサンプルレートやチャンネル数の入力も最初に変換され、出力は Windows によって
出力先デバイスに合わせて再ミックスされます。

## ゲイン {#gain}

ゲインはスライダー、−1 / +1 ボタン、またはグラフ上のゲインラインを上下にドラッグして設定します。範囲は −30 dB から +50 dB です。設定の **+50 dB を超えるゲインを許可** で +100 dB まで拡張できます。

## イコライザー {#equalizer}

**サウンド** カードには 2 つのモードがあります。

- **シンプル** -- ゲインのみを適用します。グラフ上のどこかをドラッグして設定します。
- **イコライザー** -- ゲインに加えて、最大 16 個の EQ ポイントを追加できます。

グラフには、出力のリアルタイムスペクトルに重ねて周波数特性カーブが表示されます。

### グラフの操作 {#graph-operation}

| 操作 | 方法 |
|:-------|:----------|
| **ポイントを追加** | グラフ上でダブルクリック、または **ポイントを追加** をクリック |
| **ポイントを移動** | ドラッグ — 左右で周波数、上下でゲインが変わります |
| **幅（Q）を変更** | ポイントの上でマウスホイールを回す |
| **種類の変更 / 削除** | ポイントを右クリック |
| **正確な値を入力** | ポイントをクリックし、グラフ下の入力欄（種類、周波数、ゲイン、Q）を使う |
| **すべてのポイントを消去** | **EQ をリセット** |

ポイントの種類: **ピーク**、**ローシェルフ**、**ハイシェルフ**、**ローカット（ハイパス）**、**ハイカット（ローパス）**。

## ノイズ抑制 {#noise-suppression}

声を保ったまま背景ノイズを除去します。ノイズゲートとは異なり、
**話している最中でも** 機能します。3 つの方式があります。

| 方式 | 仕組み | 得意なもの | CPU（1 コアあたり） | 遅延 |
|:-------|:-------------|:--------|:---------------|:--------|
| **軽量** | スペクトルノイズ除去（Wiener フィルター、周波数ごとにノイズフロアを学習） | 一定の雑音: ファン、ヒスノイズ、エアコン | 約 0.05 % | +10 ms |
| **標準** | [RNNoise](https://github.com/xiph/rnnoise) ニューラルネットワーク | 一定の雑音に加え、キーボード音やマウスのクリック音 | 約 0.5 % | +10 ms |
| **高精度** | [DeepFilterNet3](https://github.com/Rikorose/DeepFilterNet) ニューラルネットワーク（全帯域） | 大きな雑音や変化する雑音があっても、最も自然な声 | 約 2 % | +40 ms |

| コントロール | 説明 |
|:--------|:------------|
| **トグル** | ノイズ抑制のオン/オフを切り替えます |
| **方式** | 軽量 / 標準 / 高精度（マウスを重ねると詳細を表示） |
| **強さ** | 処理後の信号と元の信号のミックス比 |
| **音声** | 話していると抑制処理が判断している確からしさを示すメーター |

- 方式と強さはプリセットに保存されます。
- 高精度は、初めて選択したときにバックグラウンドでモデルを読み込みます
  （1 秒もかかりません）。読み込みが終わるまでは、信号は処理されずに
  そのまま通過します。ARM64 版 Windows ビルドでは使用できません。
- 軽量は、オンにしてからノイズを学習するまで 1〜2 秒かかります。
- すべての方式は実行ファイルに組み込まれています。標準は RNNoise の Rust 移植版である
  [nnnoiseless](https://github.com/jneem/nnnoiseless)（BSD-3-Clause）を、高精度は
  DeepFilterNet の `libDF` を純 Rust 製の [tract](https://github.com/sonos/tract)
  ランタイム（MIT / Apache-2.0）上で使用しています。

{: .note }
ノイズ抑制と併用しても、ノイズゲートは引き続き役立ちます。ノイズ抑制は
雑音を減衰させますが、話の合間を常に完全な無音にできるわけではありません。
ゲートは残ったノイズフロアをきれいにします。

## ノイズゲート {#noise-gate}

マイクのレベルがしきい値を下回っている間はマイクをミュートし、話の合間を完全な無音にします。

- トグルでオンにし、メーター上の **マーカーをドラッグ** して背景ノイズの少し上に合わせます（置きたい位置をクリックしても構いません）。
- メーターはゲイン適用後のレベルを表示します。声が通っている間はバッジに **通過中**、ゲートが閉じている間は **ミュート中** と表示されます。

## リミッター {#limiter}

信号の流れの最後で常に動作します。出力のピークを **出力の上限**（設定、既定値 −1.0 dBFS）以下に抑えるため、突然の大きな音でも音割れしません。レベルを下げている間は出力メーターが赤くなり、その下に *リミッター: −x dB* と表示されます。

## プリセット {#presets}

プリセットには、ゲイン、モードと EQ ポイント、ノイズ抑制（オン/オフ、方式、強さ）、ノイズゲートの設定が保存されます。

| 操作 | 方法 |
|:-------|:----|
| **適用** | **マイプリセット** または **組み込み** のプリセットをクリック |
| **新規保存** | **新規保存** を押し、名前を入力 |
| **変更を保存** | **保存**（現在のユーザープリセットを変更したときに表示） |
| **変更を取り消す** | **元に戻す** |
| **名前を変更 / 上書き / 削除** | プリセットの **⋯** ボタン、またはプリセットを右クリック |
| **フォルダーを開く** | フォルダーアイコンで、プリセットの `.json` ファイルがあるフォルダーを開きます |

変更したプリセットから別のプリセットに切り替えるときは、先に保存するかどうかを確認されます。組み込みプリセット: *原音（0 dB）*、*ブースト +12 dB*、*ブースト +24 dB*、*クリアボイス*、*ウォームボイス*、*配信向け*。

## デバイスプロファイル {#device-profiles}

デバイスプロファイルは入力と出力の組み合わせを記憶します。**ルーティング** カードの **デバイスプロファイル** リストを使います。

- **現在のデバイスをプロファイルとして保存** -- 現在の入力と出力に名前を付けて保存します。
- プロファイルを選ぶと両方のデバイスを一度に切り替えます。削除も同じリストから行えます。

プロファイルはトレイメニューからも切り替えられます。

## トレイメニュー {#tray-menu}

トレイアイコンを右クリックすると、次の操作ができます。

- **ブースト** と **ノイズ抑制** のオン/オフ
- **ゲイン** -- ±3 dB 単位の変更、よく使う値、*イコライザーを使う*
- **プリセット**、**デバイスプロファイル**、**入力**、**出力**
- **Easy MIC Booster を開く** と **終了**

## 設定の保存 {#persistent-settings}

すべての設定は `%APPDATA%\EasyMICBooster`（`settings.json` と、`Presets` および `DeviceProfiles` フォルダー）に自動で保存され、次回起動時に復元されます。v1.x の設定とプリセットは自動で取り込まれます。
