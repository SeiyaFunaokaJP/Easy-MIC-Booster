## メインインターフェース

| コントロール | 説明 |
|:-------------|:-----|
| **ゲイン** | 中央の大きなグラフで全体の出力音量を調整 |
| **フラットモード** | EQ ライン全体を上下させ、純粋なゲインコントロールとして動作 |
| **ミュート** | マイクアイコンをクリック、またはスイッチで切替 |
| **スタートアップ** | Windows 起動時に自動実行 |

## シグナルチェーン

以下の順でエフェクトが適用されます。

```
入力 → ノイズ抑制 → イコライザー → ゲイン → ノイズゲート → リミッター → 出力
```

DSP チェーンは内部的に 48 kHz モノラル（ノイズ抑制が前提とするフォーマット）で動作します。
入力サンプリングレートやチャンネル数は前段で変換され、出力デバイス側のフォーマットへは Windows が再ミックスします。

## ノイズ抑制

声を残したまま背景の雑音を除去します。ノイズゲートと違い、**発話中でも**雑音だけが消えます。方式は 3 種類から選べます。

| 方式 | 仕組み | 得意な雑音 | CPU（1 コア比） | 遅延 |
|:-----|:-------|:-----------|:----------------|:-----|
| **軽量** | スペクトル方式（周波数ごとに雑音レベルを学習するウィーナーフィルター） | ファン・ヒス・エアコンなどの定常ノイズ | 約 0.05 % | +10 ms |
| **標準** | [RNNoise](https://github.com/xiph/rnnoise)（ニューラルネットワーク） | 定常ノイズに加え打鍵音・クリック音 | 約 0.5 % | +10 ms |
| **高精度** | [DeepFilterNet3](https://github.com/Rikorose/DeepFilterNet)（ニューラルネットワーク・全帯域） | 大きな雑音や変化する雑音でも最も自然な声 | 約 2 % | +40 ms |

| コントロール | 説明 |
|:-------------|:-----|
| **トグル** | ノイズ抑制の有効 / 無効 |
| **方式** | 軽量 / 標準 / 高精度（マウスを乗せると説明を表示） |
| **強さ** | 処理後の音と元の音の混合比 |

- 方式と強さはプリセットに保存されます。
- 高精度は初めて選んだときにバックグラウンドでモデルを読み込みます（1 秒未満）。読み込みが終わるまでは無処理で通過します。ARM64 版 Windows では利用できません。
- 軽量は有効にしてから雑音を学習するまで 1〜2 秒かかります。
- いずれも実行ファイルに組み込まれています。標準は RNNoise（BSD-3-Clause）の Rust 移植 [nnnoiseless](https://github.com/jneem/nnnoiseless)、高精度は DeepFilterNet の `libDF` を pure Rust の推論エンジン [tract](https://github.com/sonos/tract)（MIT / Apache-2.0）上で動かしています。

{: .note }
ノイズ抑制を使う場合でもノイズゲートは依然として有用です。
ノイズ抑制は雑音を大きく減衰させますが完全な無音にはならないため、無音区間を完全にミュートしたい場合はゲートで残留成分をカットしてください。

## ノイズゲート

入力レベルがしきい値を下回ると音声をミュートし、発話していない区間を完全な無音にします。

- **しきい値** -- スライダーで調整。このレベルを下回る音声はミュートされます。

## イコライザー

視覚的なグラフ操作で声のトーンを整えるパラメトリックイコライザーです。

### グラフ操作

| 操作 | 方法 |
|:-----|:-----|
| **ポイント追加** | **ポイント追加**ボタン、またはグラフの空きエリアをクリック（フラットモード時を除く） |
| **ポイント移動** | 左クリックでドラッグ。周波数 (Hz) とゲイン (dB) を調整 |
| **ポイント削除** | ポイントを**右クリック** |

### モード

- **フラットモード** -- 全ポイントを固定し、1 つ動かすとライン全体が上下します。音質を変えずに音量だけ変えたい場合に便利です。
- **ブースト上限解除** -- 通常 ±50 dB の制限を ±100 dB まで拡張します。
- **周波数範囲** -- グラフ下の数値を直接編集して表示範囲（ズーム）を変更します。

### プリセット

お気に入りの EQ 設定を保存・呼び出しできます。

| 操作 | 方法 |
|:-----|:-----|
| **保存** | ドロップダウンに名前を入力し**プリセット保存**をクリック |
| **読み込み** | リストから既存のプリセットを選択 |
| **削除** | ゴミ箱アイコンをクリック |
| **フォルダを開く** | 📂 ボタンでプリセット `.json` の保存フォルダを開く |

## リミッター

突発的な大音量による音割れ（クリッピング）を防ぎます。

{: .note }
リミッターは既定で有効です。聞き手の耳を大音量から保護します。

## 設定の永続化

デバイス選択、スイッチ状態、EQ ポイント、プリセット、その他の UI 状態はアプリ終了時に `config.json` へ書き込まれ、次回起動時に復元されます。
