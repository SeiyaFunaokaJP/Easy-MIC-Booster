## 動作環境 {#system-requirements}

- **OS**: Windows 10 / 11（x64、x86 または ARM64）
- **仮想オーディオドライバー**: [VB-CABLE](https://vb-audio.com/Cable/) または同等の仮想ケーブル

Linux 版と macOS 版も公開していますが、試験的なものです。これらの環境での音声のルーティング方法は [開発者ガイド](developer-guide#supported-platforms) を参照してください。

## インストール {#installation}

### 1. VB-CABLE をインストール {#1-install-vb-cable}

1. [vb-audio.com/Cable](https://vb-audio.com/Cable/) からダウンロードします。
2. 展開して `VBCABLE_Setup_x64.exe` を **管理者として実行** します。
3. PC を再起動します。

### 2. Easy MIC Booster をインストール {#2-install-easy-mic-booster}

[Releases](https://github.com/SeiyaFunaokaJP/Easy-MIC-Booster/releases/latest) ページから最新のリリースをダウンロードします。次のいずれかを選んでください。

- **インストーラー**（`EasyMICBooster-x64-vX.Y.Z-setup.exe`）: 管理者権限なしで現在のユーザーにインストールし、スタートメニューに項目を追加します。アンインストールは Windows の 設定 > アプリ から行えます。設定は残ります。
- **ポータブル版**（`EasyMICBooster-x64-vX.Y.Z-portable.zip`）: 任意のフォルダーに展開して `EasyMICBooster.exe` を実行します。

Windows on ARM では `arm64` のファイルを、32 ビット版 Windows の場合のみ `x86` のファイルを使用してください。ARM64 版には *高精度* のノイズ抑制方式は含まれていません。

## 初期設定 {#first-time-setup}

### デバイスを選ぶ {#choose-the-devices}

左側の **ルーティング** カードで次のように設定します。

| 項目 | 選択するもの |
|:------|:-------|
| **入力（マイク）** | お使いの物理マイク、または Windows の設定に従う *既定のデバイス* |
| **出力（仮想ケーブル）** | `CABLE Input (VB-Audio Virtual Cable)` |

各リストの下のメーターは、処理前と処理後のレベルを表示します。その間の行には、有効になっている処理の概要が表示されます（例: `+12.0 dB · NS · Gate`）。

{: .warning }
出力がスピーカーやヘッドホン（既定の再生デバイス）になっていると、自分の声が聞こえてしまいます。出力には必ず仮想ケーブルを選んでください。

### ゲインを設定する {#set-the-gain}

1. 右上の **BOOST ON** が有効になっていることを確認します。
2. 普段どおりに話しながら、出力メーターのピークが緑から黄色の範囲に入るまで **サウンド** カードの **ゲイン** を上げます。−1 / +1 ボタンで 1 dB ずつ調整できます。
3. メーターが赤くなり *リミッター* と表示された場合は、リミッターがピークを抑えています。ゲインを少し下げてください。

音声が流れているときは、タイトルの横のステータス表示に **動作中** とサンプルレート、遅延が表示されます。

### 受信側のアプリを設定する {#configure-the-receiving-app}

Discord、Zoom、OBS、Teams などで音声設定を開き、マイク（入力デバイス）として `CABLE Output (VB-Audio Virtual Cable)` を選択します。

{: .warning }
Windows のサウンド設定で `CABLE Output` を **既定の再生デバイス** に設定 **しないでください**。フィードバックループ（ハウリング）が発生します。

## 日常の使い方 {#daily-use}

- **バイパス** -- **BOOST ON** をオフにすると、ゲインと EQ をかけずにマイクの音声をそのまま通します（ノイズ抑制とゲートは設定どおり動作します）。
- **トレイ** -- ウィンドウを閉じてもアプリは通知領域で動作し続けます。トレイアイコンを右クリックすると、ブーストやノイズ抑制のオン/オフ、ゲインの変更、プリセット・デバイスプロファイル・デバイスの切り替え、終了ができます。クリックするとウィンドウが開きます。
- **プリセット** -- **新規保存** でサウンドを保存し、**プリセット** カードまたはトレイからプリセットを切り替えます。[機能](features#presets) を参照してください。
- **デバイスプロファイル** -- マイクと出力の組み合わせを保存して切り替えられます（例: デスクではヘッドセット、配信では USB マイク）。[機能](features#device-profiles) を参照してください。
- **デバイスの取り外し** -- マイクや出力デバイスが見つからなくなるとステータスが赤くなります。再接続されるとルーティングは自動で再開します。

## 設定 {#settings}

右上の歯車アイコンから **設定** を開きます。

| 設定 | 説明 |
|:--------|:------------|
| **言語** | UI の言語（初回起動時は Windows の言語に従います） |
| **サインイン時に起動** | Windows へのサインイン時に自動で起動します（トレイで起動） |
| **閉じてもトレイで動作を続ける** | オフにすると、ウィンドウを閉じたときにアプリが終了します |
| **+50 dB を超えるゲインを許可** | ゲインの上限を +100 dB に引き上げます |
| **出力の上限** | リミッターが出力を抑えるピークレベル（既定値 −1.0 dBFS） |
| **アップデートを確認** | 起動時に GitHub で新しいリリースを確認します |

下のボタンから、設定フォルダー、GitHub ページ、スポンサーページを開いたり、アプリを終了したりできます。

設定、プリセット、デバイスプロファイルは `%APPDATA%\EasyMICBooster` に自動で保存され、次回起動時に復元されます。v1.x の設定は初回起動時に取り込まれます。

各オーディオ機能の詳細は [機能](features) を参照してください。
