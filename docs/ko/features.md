## 메인 창 {#main-window}

| 영역 | 기능 |
|:-----|:-------------|
| **헤더** | 상태 표시(작동 중 / 바이패스 중 / 장치 문제, 샘플 레이트 및 지연 시간 포함), **BOOST ON** 스위치, 설정 톱니바퀴 |
| **라우팅** | 레벨 미터가 있는 입력 및 출력 장치, 장치 프로필 |
| **프리셋** | 사용자 프리셋과 기본 제공 프리셋 |
| **사운드** | 게인, 간단 / 이퀄라이저 모드, 실시간 스펙트럼이 표시되는 EQ 그래프 |
| **노이즈 억제** | 켜기/끄기, 방식, 강도 |
| **노이즈 게이트** | 켜기/끄기, 임계값 |

**BOOST ON**은 게인과 EQ를 켜거나 끕니다. 꺼져 있는 동안 마이크 소리는 원래 레벨 그대로 통과하며, 노이즈 억제와 노이즈 게이트는 설정대로 계속 작동합니다.

## 신호 체인 {#signal-chain}

오디오는 다음 순서로 각 효과를 거칩니다.

```
입력 → 노이즈 억제 → 이퀄라이저 → 게인 → 노이즈 게이트 → 리미터 → 출력
```

체인은 내부적으로 48 kHz 모노(노이즈 억제기가 요구하는 형식)로 동작합니다. 따라서 어떤 샘플 레이트나 채널 수의 입력이든 처음에 변환되며, 출력은 Windows가 대상 장치에 맞게 다시 믹스합니다.

## 게인 {#gain}

슬라이더, −1 / +1 버튼, 또는 그래프의 게인 선을 위아래로 드래그해 게인을 설정합니다. 범위는 −30 dB ~ +50 dB이며, 설정에서 **+50 dB 초과 게인 허용**을 켜면 +100 dB까지 확장됩니다.

## 이퀄라이저 {#equalizer}

**사운드** 카드에는 두 가지 모드가 있습니다.

- **간단** -- 게인만 적용됩니다. 그래프의 아무 곳이나 드래그해 설정합니다.
- **이퀄라이저** -- 게인에 더해 최대 16개의 EQ 포인트를 추가합니다.

그래프는 출력의 실시간 스펙트럼 위에 응답 곡선을 표시합니다.

### 그래프 조작 {#graph-operation}

| 동작 | 조작 방법 |
|:-------|:----------|
| **포인트 추가** | 그래프를 더블클릭하거나 **포인트 추가**를 클릭 |
| **포인트 이동** | 드래그 — 좌우로 주파수, 위아래로 게인 변경 |
| **폭(Q) 변경** | 포인트 위에서 마우스 휠 스크롤 |
| **유형 변경 / 삭제** | 포인트를 우클릭 |
| **정확한 값 편집** | 포인트를 클릭하고 그래프 아래의 입력란(유형, 주파수, 게인, Q) 사용 |
| **모든 포인트 지우기** | **EQ 초기화** |

포인트 유형: **피크**, **로우 셸프**, **하이 셸프**, **로우 컷(하이패스)**, **하이 컷(로우패스)**.

## 노이즈 억제 {#noise-suppression}

목소리는 유지하면서 배경 소음을 제거합니다. 노이즈 게이트와 달리 **말하는 중에도** 작동합니다. 세 가지 방식을 사용할 수 있습니다.

| 방식 | 작동 원리 | 강점 | CPU (코어 1개) | 지연 |
|:-------|:-------------|:--------|:---------------|:--------|
| **경량** | 스펙트럼 노이즈 감소(Wiener 필터, 주파수별로 노이즈 플로어 학습) | 일정한 소음: 팬, 히스 노이즈, 에어컨 | ~0.05 % | +10 ms |
| **표준** | [RNNoise](https://github.com/xiph/rnnoise) 신경망 | 일정한 소음에 더해 키보드 소리와 마우스 클릭 | ~0.5 % | +10 ms |
| **고품질** | [DeepFilterNet3](https://github.com/Rikorose/DeepFilterNet) 신경망, 전대역 | 크거나 변화하는 소음 속에서도 가장 자연스러운 목소리 | ~2 % | +40 ms |

| 컨트롤 | 설명 |
|:--------|:------------|
| **토글** | 노이즈 억제를 켜거나 끔 |
| **방식** | 경량 / 표준 / 고품질(마우스를 올리면 자세한 설명 표시) |
| **강도** | 처리된 신호와 원래 신호의 혼합 비율 |
| **음성** | 억제기가 사용자가 말하고 있다고 판단하는 확신도를 나타내는 미터 |

- 방식과 강도는 프리셋에 저장됩니다.
- 고품질은 처음 선택할 때 백그라운드에서 모델을 불러옵니다(1초 미만). 그동안 신호는
  처리되지 않고 그대로 통과합니다. ARM64 Windows 빌드에서는 사용할 수 없습니다.
- 경량은 켠 뒤 소음을 학습하는 데 1~2초가 필요합니다.
- 모든 방식이 실행 파일에 내장되어 있습니다. 표준은 RNNoise의 Rust 포트인
  [nnnoiseless](https://github.com/jneem/nnnoiseless)(BSD-3-Clause)를, 고품질은 순수 Rust
  [tract](https://github.com/sonos/tract) 런타임(MIT / Apache-2.0) 위에서 DeepFilterNet의 `libDF`를 사용합니다.

{: .note }
노이즈 억제와 함께 노이즈 게이트를 사용하는 것도 여전히 유용합니다. 억제기는 소음을 줄이지만
말과 말 사이를 항상 완전한 무음으로 만들지는 못합니다. 게이트가 남은 잡음을 정리해 줍니다.

## 노이즈 게이트 {#noise-gate}

마이크 레벨이 임계값 아래에 있는 동안 마이크를 음소거해 말과 말 사이를 완전한 무음으로 만듭니다.

- 토글로 켠 다음, 미터의 **마커를 드래그**해 배경 소음보다 약간 위에 둡니다(또는 원하는 위치를 클릭합니다).
- 미터는 게인 적용 후의 레벨을 보여 줍니다. 목소리가 전달되는 동안에는 배지에 **통과 중**이, 게이트가 닫혀 있는 동안에는 **음소거 중**이 표시됩니다.

## 리미터 {#limiter}

체인의 마지막에서 항상 켜져 있습니다. 출력 피크를 **출력 상한**(설정, 기본값 −1.0 dBFS) 아래로 유지해 갑작스러운 큰 소리에도 클리핑이 생기지 않습니다. 레벨을 줄이고 있는 동안에는 출력 미터가 빨갛게 변하고 그 아래에 *리미터: −x dB*가 표시됩니다.

## 프리셋 {#presets}

프리셋에는 게인, 모드와 EQ 포인트, 노이즈 억제(켜기/끄기, 방식, 강도), 노이즈 게이트가 저장됩니다.

| 동작 | 방법 |
|:-------|:----|
| **적용** | **내 프리셋** 또는 **기본 제공**에서 프리셋을 클릭 |
| **새로 저장** | **새로 저장**을 누른 뒤 이름 입력 |
| **변경 사항 저장** | **저장**(현재 사용자 프리셋이 수정되면 표시됨) |
| **변경 취소** | **되돌리기** |
| **이름 바꾸기 / 덮어쓰기 / 삭제** | 프리셋의 **⋯** 버튼, 또는 프리셋을 우클릭 |
| **폴더 열기** | 폴더 아이콘으로 프리셋 `.json` 파일이 있는 폴더를 엶 |

수정된 프리셋에서 다른 프리셋으로 전환하면 Easy MIC Booster가 먼저 저장할지 묻습니다. 기본 제공 프리셋: *원음(0 dB)*, *부스트 +12 dB*, *부스트 +24 dB*, *선명한 목소리*, *따뜻한 목소리*, *스트리밍*.

## 장치 프로필 {#device-profiles}

장치 프로필은 입력/출력 조합을 기억합니다. **라우팅** 카드의 **장치 프로필** 목록을 사용하세요.

- **현재 장치를 장치 프로필로 저장** -- 현재 입력과 출력을 이름을 붙여 저장합니다.
- 프로필을 선택하면 두 장치가 한 번에 전환됩니다. 같은 목록에서 삭제할 수도 있습니다.

프로필은 트레이 메뉴에서도 전환할 수 있습니다.

## 트레이 메뉴 {#tray-menu}

트레이 아이콘을 우클릭하면 다음을 사용할 수 있습니다.

- **부스트** 및 **노이즈 억제** 켜기/끄기
- **게인** -- ±3 dB 단위 조정, 자주 쓰는 값, *이퀄라이저 사용*
- **프리셋**, **장치 프로필**, **입력**, **출력**
- **Easy MIC Booster 열기** 및 **종료**

## 설정 유지 {#persistent-settings}

모든 설정은 `%APPDATA%\EasyMICBooster`(`settings.json`, 그리고 `Presets` 및 `DeviceProfiles` 폴더)에 자동으로 저장되며 다음 실행 시 복원됩니다. v1.x의 설정과 프리셋은 자동으로 가져옵니다.
