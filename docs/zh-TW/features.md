## 主視窗 {#main-window}

| 區域 | 功能 |
|:-----|:-------------|
| **標題列** | 狀態標籤（運作中／已旁路／裝置問題，並顯示取樣率與延遲）、**BOOST ON** 開關與設定齒輪 |
| **路由** | 輸入與輸出裝置及其音量表，以及裝置設定檔 |
| **預設組** | 您的預設組與內建預設組 |
| **聲音** | 增益、簡易／等化器模式，以及附即時頻譜的 EQ 圖表 |
| **降噪** | 開／關、方式與強度 |
| **噪音閘** | 開／關與閾值 |

**BOOST ON** 用於開啟或關閉增益與 EQ。關閉時，麥克風會以原始音量直接通過；降噪與噪音閘則維持目前設定繼續運作。

## 訊號鏈 {#signal-chain}

音訊會依下列順序通過各效果：

```
Input → Noise Suppression → Equalizer → Gain → Noise Gate → Limiter → Output
```

訊號鏈內部以 48 kHz 單聲道運作——這是降噪器所需的格式——因此任何取樣率或聲道數的輸入都會先行轉換，輸出則由 Windows 針對目標裝置重新混音。

## 增益 {#gain}

可使用滑桿、−1 / +1 按鈕，或在圖表上上下拖曳增益線來設定增益。範圍為 −30 dB 到 +50 dB；在設定中開啟 **允許增益超過 +50 dB** 可擴充到 +100 dB。

## 等化器 {#equalizer}

**聲音** 卡片有兩種模式：

- **簡易** -- 只套用增益。在圖表上任意位置拖曳即可設定。
- **等化器** -- 在增益之外，最多可再加入 16 個 EQ 控制點。

圖表會在輸出的即時頻譜上顯示響應曲線。

### 圖表操作 {#graph-operation}

| 動作 | 操作方式 |
|:-------|:----------|
| **新增控制點** | 在圖表上按兩下，或按一下 **新增控制點** |
| **移動控制點** | 拖曳控制點——左右移動改變頻率，上下移動改變增益 |
| **變更寬度（Q）** | 在控制點上捲動滑鼠滾輪 |
| **變更類型／刪除** | 在控制點上按右鍵 |
| **編輯精確數值** | 按一下控制點，並使用圖表下方的欄位（類型、頻率、增益、Q） |
| **清除所有控制點** | **重設 EQ** |

控制點類型：**峰值**、**低架**、**高架**、**低切（高通）** 與 **高切（低通）**。

## 降噪 {#noise-suppression}

在保留人聲的同時去除背景噪音。與噪音閘不同，這項功能 **即使在您說話時也能運作**。共有三種方式可供選擇：

| 方式 | 運作原理 | 擅長處理 | CPU（單核心） | 延遲 |
|:-------|:-------------|:--------|:---------------|:--------|
| **輕量** | 頻譜降噪（維納濾波器，依頻率學習噪音底） | 穩定噪音：風扇、底噪、冷氣 | 約 0.05 % | +10 ms |
| **標準** | [RNNoise](https://github.com/xiph/rnnoise) 神經網路 | 穩定噪音，以及鍵盤聲與滑鼠點擊聲 | 約 0.5 % | +10 ms |
| **高精度** | [DeepFilterNet3](https://github.com/Rikorose/DeepFilterNet) 神經網路，全頻帶 | 即使噪音很大或不斷變化，人聲也最自然 | 約 2 % | +40 ms |

| 控制項 | 說明 |
|:--------|:------------|
| **開關** | 開啟或關閉降噪 |
| **方式** | 輕量／標準／高精度（將滑鼠停留在上方可查看詳細說明） |
| **強度** | 處理後訊號與原始訊號的混合比例 |
| **人聲** | 顯示降噪器判斷您正在說話的信心程度的音量表 |

- 方式與強度會儲存在預設組中。
- 高精度在首次選用時會於背景載入模型（遠少於一秒）；載入完成前，訊號會不經處理直接通過。ARM64 Windows 版本無法使用此方式。
- 輕量在開啟後需要一到兩秒來學習噪音。
- 所有方式都內建於執行檔中：標準使用 [nnnoiseless](https://github.com/jneem/nnnoiseless)，這是 RNNoise 的 Rust 移植版（BSD-3-Clause）；高精度則在純 Rust 的 [tract](https://github.com/sonos/tract) 執行環境（MIT / Apache-2.0）上使用 DeepFilterNet 的 `libDF`。

{: .note }
即使已使用降噪，噪音閘仍然有用——降噪器會減弱噪音，但在語句之間不一定能達到完全無聲。噪音閘可清除殘留的噪音底。

## 噪音閘 {#noise-gate}

當麥克風音量持續低於閾值時將其靜音，讓語句之間的空檔完全無聲。

- 使用開關將其開啟，然後將音量表上的 **標記拖曳** 到略高於背景噪音的位置（或直接按一下想放置的位置）。
- 音量表顯示的是套用增益後的音量；當您的聲音被傳出時，標籤顯示 **通過中**，噪音閘關閉時則顯示 **已靜音**。

## 限幅器 {#limiter}

固定在訊號鏈末端運作。它會將輸出峰值保持在 **輸出上限**（設定，預設 −1.0 dBFS）以下，讓突如其來的大聲也不會爆音。在壓低音量期間，輸出音量表會變成紅色，並在下方顯示 *限幅器：−x dB*。

## 預設組 {#presets}

預設組會儲存增益、模式與 EQ 控制點、降噪（開／關、方式、強度）以及噪音閘。

| 動作 | 方法 |
|:-------|:----|
| **套用** | 在 **我的預設組** 或 **內建** 中按一下預設組 |
| **另存為新預設組** | 按一下 **另存為新預設組**，然後輸入名稱 |
| **儲存變更** | **儲存**（目前的使用者預設組被修改時才會出現） |
| **復原變更** | **還原** |
| **重新命名／覆寫／刪除** | 預設組上的 **⋯** 按鈕，或在預設組上按右鍵 |
| **開啟資料夾** | 資料夾圖示會開啟存放預設組 `.json` 檔案的資料夾 |

當您從已修改的預設組切換到其他預設組時，Easy MIC Booster 會先詢問是否要儲存。內建預設組：*原音（0 dB）*、*增強 +12 dB*、*增強 +24 dB*、*清晰人聲*、*溫暖人聲* 與 *直播*。

## 裝置設定檔 {#device-profiles}

裝置設定檔會記住一組輸入／輸出的組合。請使用 **路由** 卡片中的 **裝置設定檔** 清單：

- **將目前裝置儲存為裝置設定檔** -- 以指定名稱儲存目前的輸入與輸出。
- 選擇設定檔即可同時切換兩個裝置；也可以在同一個清單中刪除設定檔。

也可以從系統匣選單切換設定檔。

## 系統匣選單 {#tray-menu}

在系統匣圖示上按右鍵可使用：

- **增強** 與 **降噪** 的開／關
- **增益** -- 以 ±3 dB 為單位調整、常用數值，以及 *使用等化器*
- **預設組**、**裝置設定檔**、**輸入** 與 **輸出**
- **開啟 Easy MIC Booster** 與 **結束**

## 設定的保存 {#persistent-settings}

所有內容都會自動儲存到 `%APPDATA%\EasyMICBooster`（`settings.json`，以及 `Presets` 與 `DeviceProfiles` 資料夾），並在下次啟動時還原。v1.x 的設定與預設組會自動匯入。
