## 主窗口 {#main-window}

| 区域 | 作用 |
|:-----|:-------------|
| **标题栏** | 状态标签（运行中 / 已旁路 / 设备问题，并显示采样率和延迟）、**BOOST ON** 开关和设置齿轮 |
| **路由** | 带电平表的输入和输出设备，以及设备配置 |
| **预设** | 你的预设和内置预设 |
| **声音** | 增益、简单 / 均衡器模式，以及带实时频谱的 EQ 图 |
| **降噪** | 开/关、方式和强度 |
| **噪声门** | 开/关和阈值 |

**BOOST ON** 用于开启或关闭增益和 EQ。关闭时，麦克风声音以原始电平直接通过；降噪和噪声门仍按当前设置工作。

## 信号链 {#signal-chain}

音频按以下顺序经过各个效果：

```
输入 → 降噪 → 均衡器 → 增益 → 噪声门 → 限幅器 → 输出
```

信号链内部以 48 kHz 单声道运行——这是降噪器所需的格式——因此任何采样率或声道数的输入都会预先转换，输出则由 Windows 针对目标设备重新混音。

## 增益 {#gain}

可以通过滑块、−1 / +1 按钮，或在图上上下拖动增益线来设置增益。范围为 −30 dB 到 +50 dB；在设置中开启 **允许增益超过 +50 dB** 后可扩展到 +100 dB。

## 均衡器 {#equalizer}

**声音** 卡片有两种模式：

- **简单** -- 仅应用增益。在图上任意位置拖动即可设置。
- **均衡器** -- 在增益基础上最多添加 16 个 EQ 控制点。

图中在输出的实时频谱上显示响应曲线。

### 图形操作 {#graph-operation}

| 操作 | 方法 |
|:-------|:----------|
| **添加控制点** | 在图上双击，或点击 **添加控制点** |
| **移动控制点** | 拖动它——左右改变频率，上下改变增益 |
| **改变宽度（Q）** | 在控制点上滚动鼠标滚轮 |
| **更改类型 / 删除** | 右键单击控制点 |
| **输入精确数值** | 点击控制点，然后使用图下方的输入框（类型、频率、增益、Q） |
| **清除所有控制点** | **重置 EQ** |

控制点类型：**峰值**、**低架**、**高架**、**低切（高通）** 和 **高切（低通）**。

## 降噪 {#noise-suppression}

在保留人声的同时去除背景噪音。与噪声门不同，它**即使在你说话时**也能工作。共有三种方式：

| 方式 | 原理 | 擅长 | CPU（单核） | 延迟 |
|:-------|:-------------|:--------|:---------------|:--------|
| **轻量** | 频谱降噪（维纳滤波，按频率学习噪声底） | 稳定噪音：风扇、底噪、空调 | ~0.05 % | +10 ms |
| **标准** | [RNNoise](https://github.com/xiph/rnnoise) 神经网络 | 稳定噪音以及键盘声和鼠标点击声 | ~0.5 % | +10 ms |
| **高精度** | [DeepFilterNet3](https://github.com/Rikorose/DeepFilterNet) 神经网络，全频带 | 即使噪音很大或不断变化，人声也最自然 | ~2 % | +40 ms |

| 控件 | 说明 |
|:--------|:------------|
| **开关** | 开启或关闭降噪 |
| **方式** | 轻量 / 标准 / 高精度（悬停查看详情） |
| **强度** | 处理后信号与原始信号的混合比例 |
| **人声** | 显示降噪器判断你正在说话的置信度的电平表 |

- 方式和强度会保存在预设中。
- 首次选择高精度时，会在后台加载模型（远不到一秒）；在此之前信号不经处理直接通过。ARM64 Windows 版本不提供此方式。
- 轻量方式开启后需要一到两秒来学习噪音。
- 所有方式都内置在可执行文件中：标准使用 [nnnoiseless](https://github.com/jneem/nnnoiseless)，即 RNNoise 的 Rust 移植版（BSD-3-Clause）；高精度在纯 Rust 的 [tract](https://github.com/sonos/tract) 运行时（MIT / Apache-2.0）上使用 DeepFilterNet 的 `libDF`。

{: .note }
在降噪之外再使用噪声门仍然很有用——降噪器会衰减噪音，但在语句之间不一定总能达到完全静音。噪声门可以清除残留的底噪。

## 噪声门 {#noise-gate}

当麦克风电平低于阈值时将其静音，让语句之间的停顿完全无声。

- 用开关将其开启，然后**拖动电平表上的标记**到略高于背景噪音的位置（或直接点击目标位置）。
- 电平表显示增益之后的电平；有声音通过时标签显示 **通过中**，噪声门关闭时显示 **已静音**。

## 限幅器 {#limiter}

始终在信号链末端启用。它将输出峰值保持在 **输出上限**（设置中，默认 −1.0 dBFS）以下，因此突然的大声也不会削波。在压低电平时，输出电平表会变红，并在下方显示 *限幅器：−x dB*。

## 预设 {#presets}

预设会保存增益、模式和 EQ 控制点、降噪（开/关、方式、强度）以及噪声门。

| 操作 | 方法 |
|:-------|:----|
| **应用** | 在 **我的预设** 或 **内置** 中点击一个预设 |
| **另存为新预设** | 点击 **另存为新预设**，然后输入名称 |
| **保存更改** | **保存**（当前用户预设被修改后出现） |
| **撤销更改** | **还原** |
| **重命名 / 覆盖 / 删除** | 预设上的 **⋯** 按钮，或右键单击预设 |
| **打开文件夹** | 文件夹图标会打开存放预设 `.json` 文件的文件夹 |

从已修改的预设切换到其他预设时，Easy MIC Booster 会先询问是否保存。内置预设：*原声（0 dB）*、*增强 +12 dB*、*增强 +24 dB*、*清晰人声*、*温暖人声* 和 *直播*。

## 设备配置 {#device-profiles}

设备配置会记住一组输入/输出设备。请使用 **路由** 卡片中的 **设备配置** 列表：

- **将当前设备保存为设备配置** -- 以指定名称保存当前的输入和输出设备。
- 选择一个设备配置即可同时切换两个设备；也可以在同一列表中将其删除。

也可以从托盘菜单切换设备配置。

## 托盘菜单 {#tray-menu}

右键单击托盘图标可以使用：

- **增强** 和 **降噪** 的开/关
- **增益** -- 以 ±3 dB 步进调整、常用数值以及 *使用均衡器*
- **预设**、**设备配置**、**输入** 和 **输出**
- **打开 Easy MIC Booster** 和 **退出**

## 设置持久保存 {#persistent-settings}

所有内容都会自动保存到 `%APPDATA%\EasyMICBooster`（`settings.json`，以及 `Presets` 和 `DeviceProfiles` 文件夹），并在下次启动时恢复。v1.x 的设置和预设会被自动导入。
